# Credit Card Fraud Detection

This project explores credit-card fraud detection under extreme class imbalance. The notebook emphasizes precision-recall metrics and cost-aware decision thresholds rather than accuracy alone.

## Dataset

The notebook uses the Kaggle [Credit Card Fraud Detection](https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud) dataset. Download `creditcard.csv` and place it in the project directory before running the notebook. The dataset is not stored in this repository because it exceeds GitHub's 100 MB file limit.

## Run the notebook

Open `credit-card-fraud-detection-pr-auc-beats-accuracy.ipynb` in Jupyter or VS Code and run its cells. The notebook searches the current working directory for `creditcard.csv` and also checks supported Kaggle input locations.
